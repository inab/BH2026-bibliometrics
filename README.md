# BH2026-bibliometrics

Bibliometric analyses of research software citations in the life sciences.

This repository started at the [BioHackathon Europe 2026](https://biohackathon-europe.org/), in Project 17: [*Bridging Literature and Practice: Tool Co-citation Networks from Publications and Registered Workflows*](https://github.com/inab/BH2026-InSoLiTo).

## Scope

The project built tool co-citation and citation order networks for [InSoLiTo](https://github.com/inab/BH2026-InSoLiTo). This repository holds the analyses that go beyond InSoLiTo and look at research software as a subject of study, for example:

- how tools are cited over time and across research communities
- how tool updates relate to their use
- which tools are cited together more often than expected

## Data sources

- Open Access full-text articles from [Europe PMC](https://europepmc.org/)
- Tool metadata and publications from [bio.tools](https://bio.tools/)
- [OpenAlex](https://openalex.org/)
